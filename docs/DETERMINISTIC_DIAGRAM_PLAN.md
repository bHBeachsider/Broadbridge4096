# Deterministic diagram detection plan

User-directed implementation, 27 September 2026. Success means measured geometry extraction with explicit evidence, not training approval. Foundry #16 and Broadbridge #20 stay drafts; successors remain drafts. No prompt optimization, training, EC2/GPU, production, client drawings or bulk downloads.

1. Implement schema rules first: every non-unknown direction cites an attached detected arrow; a direction must agree with tip/base; connection evidence and the applied convention are required. Plain X intersections are non-connecting even when their vector primitives end at the crossing. Tees and shared endpoints connect; dots override crossing separation. Treat this as the declared project drawing convention, not certification of every ISA drawing revision or plant legend.
2. Extract actual PDF path/DXF geometry. Route image-only inputs to local raster segmentation/skeletonization; reject mixed/unsupported inputs explicitly. Fixed tolerances use page units or pixels and are logged. Real symbol libraries, OCR and plant legends remain separate work.
3. Freeze **12 new synthetic development drawings** and PDF/DXF/PNG siblings, construction-model snapshots, references, seeds, label-only port annotations and all checksums before executing either detector or baseline. Cover dense crossings, dotted/undotted tees, hop, broken line, no-arrow lines, forward/reverse, rotated and small arrows. No training. Independent source graph from pyDEXPI construction; no gold edges into detection.
4. Use the existing unchanged v2 prompt, model digest and settings for **12 baseline requests**, one per same PNG, on the already installed local CPU Docker stack. No retries or new prompting. The deterministic routes receive only input bytes plus label/port locations, never the graph. This is conditional connectivity evaluation with supplied ports, not end-to-end OCR parity against the image-only baseline. The set is new development data, not independently reviewed held-out data.
5. Report PDF vector, DXF vector, raster and baseline separately and per failure class. Count every missing/failed result against recall. Known-arrow reversal denominator is the number of known directed reference edges; also report direction accuracy/coverage and unsupported claims on undirected reference edges. Preserve misses; do not alter the frozen set or parameters to make the final benchmark pass.
6. Mark the original experiment `provenance: retrospective-checksum` and `gate_eligible: false` through a disposition record without rewriting raw receipts. Require pinned crop-history metadata before any future diagram-training release; that implementation remains deferred. Native missing endpoints stay null; no geometry guess repairs source facts.

Optional CPU dependencies are isolated and pinned. PID2Graph's record was rechecked: CC BY-SA 4.0 is declared for Dataset PID and synthetic symbols; the full archive is 9.3 GB and is not downloaded. Existing sample remains eval-only, with unresolved upstream rights/physical-topology mapping. Use original construction data here.

Final validation: new schema/geometry/extractor/experiment integrity tests, existing 724/420 test coverage, independent read-only code review, exact archived replay, draft PRs and CI. Stop before any download over 1 GB, GPU need or client drawing. Leave local vision stack stopped after the baseline.
