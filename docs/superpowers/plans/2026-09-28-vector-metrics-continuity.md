# Vector metrics and native curve continuity

Approved scope: first batch of the diagram assessment recommendations. Generic code
belongs in slm-foundry; evaluation policy and evidence belong in Broadbridge4096.
Use the existing isolated checkouts and draft successor PRs. No model calls, EC2,
GPU, training, production changes, client drawings, or new dataset downloads.

1. Define the metric contract: integer denominators, raw versus accepted graphs,
   direction precision versus recovery, zero-denominator handling, two-sided 95%
   Wilson intervals, critical-error counts and explicit qualification blockers.
   Tests must distinguish point performance from confidence and independence.
2. Reproduce the DXF hop failure with new engine-level development fixtures.
   Preserve entity/path identity and ordered curve samples. Sampling vertices
   must not become branches; true endpoint tees and junction dots must survive.
   Test rotation, sampling density, input order, nearby disconnected paths and
   real DXF ARC/SPLINE/bulged-polyline inputs. Keep the evidence checker strict.
3. Replay CPU extraction against the immutable twelve-drawing regression set.
   Reuse the archived vision baseline. Write a new receipt/output directory;
   preserve all old inputs, references, model results and result reports.
4. Produce a denominator-explicit report by route, drawing and failure category,
   with confidence intervals and a Bill convention-review checklist. Regression
   improvements do not qualify the route or unblock diagram training.
5. Run focused and full offline suites, inspect the diff, obtain a fresh read-only
   review, fix material findings, and publish draft successors to #17 / #21.

Subsequent batches remain separately gated: independent vector qualification
families and reviewer overlays; raster line/arrow recovery; signed source-only
reference tracing; crop-history pinning; rights and release acceptance. A second
identical deterministic replay proves reproducibility, not independent validation.

Acceptance for this repair: a continuous hop plus a crossing line yields exactly
two non-connecting through paths; no approximation-generated junctions; no new
unsupported directions; real tees/dots remain connected. A visible unexplained
break stays unresolved. Do not repair gold labels after seeing predictions.
